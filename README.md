# ADAM RUN · demo 1.1.0

Flutter для Android/iOS и FastAPI. Вход по **телефону или email**, тестовый код **00000**. Главная, шагомер, офлайн-карта Бишкека, два маршрута, профиль с фото и общие рейтинги.

## Запуск

Нужны Flutter 3.47.5 / Dart 3.13.4, Python 3.13+, Java 21 для Android, Xcode для iOS. Минимальные ОС: Android 9 и iOS 15.5. Версии пакетов зафиксированы в `mobile/pubspec.lock` и `backend/requirements.txt`.

```sh
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

В другом терминале:

```sh
cd mobile
flutter pub get
flutter run
```

По умолчанию Android эмулятор использует `http://10.0.2.2:8000`, iOS Simulator — `http://127.0.0.1:8000`. Для физического устройства запустить API с `--host 0.0.0.0` в доверенной локальной сети и передать адрес компьютера:

```sh
flutter run --dart-define=API_BASE_URL=http://192.168.1.10:8000
```

Для web-проверки интерфейса: `flutter run -d chrome --web-port=7357`. В браузере шагомер недоступен — приложение показывает это явно. Настоящие шаги проверяются на телефоне.

## Что работает

- Регистрация с никнеймом, вход, сохранение сессии в защищённом хранилище, ротация refresh-токена, выход. Код действует 5 минут, максимум 5 попыток; повторное использование и старый код после повторного запроса запрещены. Запросы ограничены по контакту/IP. Номер вводится с кодом страны; SMS и письма не отправляются.
- Главная: реальные шаги, цель 1 000–50 000, последние 7 дней, серия по доступной истории, переключение режимов, карта, локальная коллекция, личное время Run Race.
- Walk Quest **«Городская птица»**, около 5,38 км; Run Race **«Парковый Sprint»**, около 1,23 км. Оба — демонстрационные маршруты по геометрии пешеходных путей OSM. Партнёров и рекламных предложений нет.
- MapLibre с локальными векторными тайлами всего Бишкека (358 тайлов, около 10 МБ). Свободные жесты, масштаб, полноэкранный режим, улицы и названия. Область [74.42, 42.77, 74.80, 42.97] доступна без интернета; за её пределами офлайн-деталей нет. Web-библиотека MapLibre GL также включена локально (версия 5.6.2).
- Старт возле начала пути, контроль качества GPS, последовательное заполнение рисунка, пауза/продолжение, восстановление незаконченного прохождения после перезапуска. Запись маршрута автоматически приостанавливается в фоне; шагомер работает независимо.
- После подтверждённого старта: стрелка направления, пульсация, таймер и пауза. Во время GPS-поиска показано отдельное состояние.
- Завершённые маршруты сохраняются локально и отправляются на сервер с уникальным ID. Сервер проверяет порядок GPS-точек, точность, скорость и полный маршрут; точные GPS-записи после проверки не хранятся. Повторная отправка не дублирует результат.
- Run Race: лучшее время на трассе, включая паузы. Walk Quest: число дней с завершённым рисунком, максимум один балл за день. Периоды «месяц» / «всё время», равные результаты — равные места, собственная позиция и публичные профили участников. Без выдуманных игроков/призов.
- Для рейтинга старт подтверждается сервером; старт без сети сохраняется как личный результат. Это базовая проверка MVP, не защита от всех видов подмены GPS на модифицированных устройствах.
- Профиль: фото из галереи, никнейм, город, описание, цель, статистика, история, достижения и коллекция. Другим доступны только фото, никнейм, достижения и пройденные карты. Фото нормализуется в JPEG 512×512 без EXIF и хранится в PostgreSQL.
- Сохранение цели ждёт подтверждения сервера, показывает ожидание/ошибку, затем обновляет главный экран и кэш сессии.

## Шагомер

- **iOS:** `CMPedometer` (Core Motion), точный системный счётчик телефона и история от локальной полуночи. История восстанавливается после закрытия приложения. Шаги Apple Watch сюда не прибавляются.
- **Android:** только `TYPE_STEP_COUNTER` телефона, foreground service с уведомлением. Данные часов/Health Connect и других приложений не подмешиваются. Сохраняются базовый счётчик и дни; повторные, устаревшие, уменьшающиеся показания и невозможные скачки отбрасываются. Перезагрузка определяется по `BOOT_COUNT`.
- База до первого подключения не считается. Неоднозначный интервал через полночь/перезагрузку не приписывается новому дню. Приложение честно отмечает неполное покрытие.
- GPS, расстояние и движения экрана **не используются для расчёта шагов**. Нет датчика/разрешения — нет выдуманного числа. Показания обновляются каждые 3 секунды и при возврате; сам датчик может присылать данные пачками.
- В профиле есть проверка на 100 шагов с относительным счётчиком; она не меняет дневной результат.

Нулевую погрешность обещать нельзя: она зависит от телефона и положения устройства. Перед выпуском нужен контрольный проход с ручным подсчётом на реальном Android/iPhone, включая заблокированный экран, перезапуск, отказ в разрешении и переход через полночь. Симулятор не проверяет точность физического датчика.

cd backend

flutter analyze
flutter test
flutter build apk --debug
flutter build ios --simulator --no-codesign

./gradlew :app:testDebugUnitTest

```sh

```

Проверка создаёт тестового пользователя, проходит вход, сохраняет цель и профиль на сервере, открывает оба режима, рейтинг и полноэкранную карту.

## Ограничения этапа

API использует SQLite локально и PostgreSQL в размещённой версии. Новые таблицы добавляются без изменения исходных пользователей и сессий. QR, партнёры и реальные призы пока не подключены. Фоновый GPS не ведётся: при сворачивании маршрут ставится на паузу, аппаратный шагомер продолжает работу.

Фиксированный OTP разрешён при `APP_ENV=development/test/demo` и `TEST_AUTH_ENABLED=true`; в production запрещён. Это только тестовые аккаунты: код `00000` не доказывает владение номером/почтой. Для публичного запуска нужны реальные SMS/email-провайдеры. Телефон и почта при отдельных регистрациях создают отдельные аккаунты.

Развёртывание и подписанная APK: [docs/deployment.md](docs/deployment.md).

Городские маршруты требуют проверки на месте перед публичным запуском. Источники и лицензии: [docs/data-sources.md](docs/data-sources.md).
