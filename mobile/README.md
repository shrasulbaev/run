# ADAM RUN · Flutter

Мобильный клиент. Запуск API, настройка адреса сервера, устройство шагомера и проверки описаны в [основном README](../README.md).

```sh
flutter pub get
flutter run
```

Тестовый код входа: **00000**. Реальный шагомер доступен только на поддерживаемом телефоне с разрешением на физическую активность.
