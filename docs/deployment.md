# Размещение тестового ADAM RUN и APK

Сервер: Render Free, база: Neon Free PostgreSQL 17 во Франкфурте. Конфигурация для повторного размещения находится в `render.yaml`. Для создания через Render API без поддержки rootDir команды начинаются с `cd backend &&`. Автоматический деплой выключен: обновления публикуются явно после проверок.

Переменные сервера:

- `APP_ENV=demo`, `TEST_AUTH_ENABLED=true` — явно тестовый вход `00000`.
- `DATABASE_URL` — строка подключения из Neon; принимаются `postgresql://` и `postgres://`, драйвер psycopg выбирается автоматически. Соединение использует TLS.
- `JWT_SECRET` — отдельные случайные 256 бит; не хранить в репозитории или APK.
- `PYTHON_VERSION=3.13.7`, `CORS_ORIGINS=[]` — браузерные клиенты не разрешены, Android/iOS не используют CORS.

Данные пользователей остаются в PostgreSQL при перезапуске Render. SQLite в размещённом режиме запрещена. `/health` проверяет соединение с базой. Перед выдачей APK выполнить:

```sh
python3 scripts/smoke_api.py https://<адрес-сервера>
```

## Подписанная APK

Нужны Java 21 и Flutter из README. Создание ключа выполняется один раз:

```sh
python3 scripts/create_android_signing.py
python3 scripts/build_android_release.py --api-url https://<адрес-сервера>
```

`--flutter /полный/путь/flutter` задаёт Flutter, если он отсутствует в PATH. Сборка проверяет доступность реального HTTPS API и создаёт `artifacts/adam-run-1.0.0-demo.apk` и SHA-256. В APK включается только публичный адрес сервера; серверные секреты туда не попадают.

Сохранить резервную копию `mobile/android/key.properties` и `mobile/android/keystore/adam-run-release.jks` в защищённом месте. Они исключены из Git, права файлов — 0600. Следующие обновления нужно подписывать тем же ключом. Если раньше была установлена debug-сборка, перед установкой release требуется удалить её из-за другого сертификата; локальные результаты при удалении потеряются.

## Ограничения бесплатного тестового сервера

[Render Free](https://render.com/docs/free) засыпает после 15 минут без входящих запросов. Первый вход после паузы может занять около минуты; приложение допускает ожидание до 90 секунд и сообщает о задержке. Квота 750 часов делится между бесплатными сервисами одного рабочего пространства. Лимиты трафика и сборок также общие. Новый сервис создаётся строго на Free.

[Neon Free](https://neon.com/pricing) имеет ограничение вычислений и хранения, но не 30-дневный срок жизни базы Render Free Postgres. Проверенный тариф организации — Free. При исчерпании бесплатных лимитов сервис может стать недоступен; переход на платные тарифы не настроен.

Код `00000` не подтверждает владение почтой. Это публично доступный тестовый стенд, использовать только вымышленные тестовые аккаунты. Точность физического датчика шагов не подтверждается серверными тестами.
