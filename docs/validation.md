# Проверка MVP · 16 ноября 2026

- FastAPI: 5 тестов прошли (регистрация, коды, ограничения запросов, сессии, цель, выход, защита production).
- Flutter: анализ без замечаний, 7 тестов прошли (авторизация, обновление токенов, последовательность GPS, плохая точность/скачки, сохранение прогресса, серия дней, встроенные трассы).
- Android: 3 JUnit-теста счётчика прошли (база, повторные события, перезагрузка, полночь); debug APK успешно собран с Java 21.
- iOS Simulator, iPhone 18 Pro: интеграционный сценарий прошёл — регистрация с 00000, запись/чтение защищённой сессии, доступность нативного канала шагомера, сохранение цели 10 000 на API, переключение Walk Quest / Run Race.
- Web: release-сборка успешна; в изолированном Chrome проверены регистрация, оба режима и восстановление входа после перезагрузки. Необработанных JavaScript-ошибок нет; главная и карты проверены визуально.

Физический подсчёт шагов и прогулка по трассам на реальном устройстве пока не проверялись. Симулятор подтверждает работу интерфейса и нативного канала, но не измеряет погрешность датчика. Сборка для публикации в магазинах не выполнялась.

Команды воспроизведения — в основном README. Интеграционный сценарий требует работающий локальный API. APK по умолчанию обращается к API через Android-эмулятор (10.0.2.2:8000); для телефона при сборке нужен API_BASE_URL с доступным телефону адресом.
